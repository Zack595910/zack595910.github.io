核心特性

不只是桌面模拟，更是一个完整的浏览器操作系统

🖥️

完整桌面环境

窗口管理（拖拽/缩放/贴边/最小化动画）、任务栏、开始菜单磁贴、右键二级菜单、系统托盘、回收站、通知中心、存储管理

🐍

Python 运行时

内置 Pyodide 0.27.0，支持 tkinter 模拟层（Tk/Label/Button/Entry/Frame/Canvas/Listbox/Notebook 等20+组件）

👥

多用户系统

每用户独立文件和设置，密码/无密码登录，头像标识，切换用户，自动保存，锁屏保护

📁

虚拟文件系统

localStorage 持久化，文件读写删、回收站、虚拟文件夹、拖拽上传、下载、搜索分类、容量监控预警

📜

rf 脚本引擎

类 bat 命令式脚本，15+命令，window/label/button/canvas/draw/if/menu/msg/ask/set 等

⚡

KD 应用系统

完整 HTML 应用通过 iframe 运行，可调用 tkemu API，永久安装到开始菜单

🔧

sys 系统更新

TI 级最高权限，令牌验证，进度条安装，持久化存储，启动自动应用

🖥️

Windows Control

仿 Windows 7 控制面板，类别/图标视图、搜索、侧边栏、25+设置项，全部图形化操作

📋

🔌

硬件桥接

摄像头拍照、麦克风录音、U盘文件导入、打印文件、音频测试

📁

右键二级菜单

桌面右键分类管理，新建/打开/管理工具分组，悬停展开子菜单

🔄

系统还原与任务计划

rf 脚本命令参考

命令说明示例
window创建窗口window "标题" 400 300
label显示文字label "你好" center
button创建按钮button "点击" run ... end
close关闭窗口close
menu菜单栏menu "文件"
menuitem菜单项menuitem "打开" run ... end
canvas创建画布canvas 480 300
drawJS 绘制块draw ... end
print输出到 Shellprint "Hello"
python执行 Pythonpython "print(1+1)"
msg消息框msg "标题" "内容"
ask询问框ask "标题" "内容" -> 变量
input输入框input "提示" -> 变量
set设置变量set x = 100
if条件判断if x == "yes" then ... end
wait等待毫秒wait 1000

核心特性

不只是桌面模拟，更是一个完整的浏览器操作系统

🖥️

完整桌面环境

窗口管理、任务栏、开始菜单、右键菜单、系统托盘、回收站、通知中心，还原 Windows 操作习惯

🐍

Python 运行时

内置 Pyodide 0.27.0，支持 tkinter 模拟层（Tk/Label/Button/Entry/Frame/Canvas/Listbox/Notebook 等20+组件）

📁

虚拟文件系统

localStorage 持久化，文件读写删、回收站、虚拟文件夹标签、本地上传下载、搜索分类筛选

📜

rf 脚本引擎

类 bat 命令式脚本语言，15+命令，支持 window/label/button/canvas/draw/if/menu/msg/ask/set

⚡

KD 应用系统

完整 HTML 应用通过 iframe 运行，可调用 tkemu API，永久安装到开始菜单

🔧

sys 系统更新

TI 级最高权限，令牌验证保护，进度条安装，持久化存储，启动自动应用

rf 脚本命令参考

命令说明示例
window创建窗口window "标题" 400 300
label显示文字label "你好" center
button创建按钮button "点击" run ... end
close关闭窗口close
menu菜单栏menu "文件"
menuitem菜单项menuitem "打开" run ... end
canvas创建画布canvas 480 300
drawJS 绘制块draw ... end
print输出到 Shellprint "Hello"
python执行 Pythonpython "print(1+1)"
msg消息框msg "标题" "内容"
ask询问框ask "标题" "内容" -> 变量
input输入框input "提示" -> 变量
set设置变量set x = 100
if条件判断if x == "yes" then ... end
wait等待毫秒wait 1000

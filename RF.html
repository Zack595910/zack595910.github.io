RF 是什么

一门用纯 C 语言编写的轻量级编程语言

RF（Rapid Forge）是一门用纯 C 语言编写的轻量级编程语言。
语法独创、中英文编码友好，能调用 Win32 API 和任意 DLL，
支持 2D/3D 图形、多线程、文件操作，并自带包管理和图形化设计器。
目标：让新手快速上手写 Windows 桌面程序和小游戏。

语法示例

简洁直观的语法，几分钟上手

📝 变量与运算
x = 10 y = 20 z = x + y print(z)
🔄 条件与循环
if (x > 5) { print("x > 5") } else { print("x <= 5") } i = 0 while (i < 5) { print(i) i = i + 1 } for (j = 0; j < 3; j = j + 1) { print(j) }
🔧 函数定义
func add(a, b) { return a + b } result = add(10, 20) print(result) // 30
🪟 创建窗口
new_window("RF 窗口", 700, 550) create_button("按钮", 20, 40, 100, 30) create_label("标签", 20, 80, 150, 25) create_textbox("文本框", 20, 110, 200, 25) run()
🎮 2D 绘图
dx2d_init(800, 600) dx2d_rect(100, 100, 200, 150, 255, 0, 0) dx2d_circle(400, 300, 80, 0, 255, 0) dx2d_text("Hello RF", 300, 400, 255, 255, 0) dx2d_present()
🎯 游戏循环
func init() { print("Game Init") } func update() { print("Update") } func render() { dx2d_rect(100, 100, 200, 150, 255, 0, 0) dx2d_present() } game_loop("init", "update", "render")
🔌 调用系统 API
callAPI("user32.dll", "MessageBoxA", 0, "Hello", "RF", 0) callAPI("kernel32.dll", "Beep", 800, 300)
🧵 多线程
func task(name) { print("Thread: " + name) } thread_run("task", "hello") thread_wait_all()

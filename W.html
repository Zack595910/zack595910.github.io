W 是什么

专为 Windows 界面开发设计的语言

W 语言是专为 Windows 界面开发设计的语言。
纯 C 实现，直接调 Win32 原生 API，.w 文件即写即运行。
目标是让 Windows 界面开发像写 HTML 一样简单，但跑的是原生窗口。

核心特性

语言、UI、系统三层能力全覆盖

🔤

语言层

变量（全局/局部）、函数（参数/返回值/递归）、if/else、for/while、数组、字符串拼接、完整运算符

🪟

UI 层

原生窗口、深色 Metro 主题、11 种 Win32 控件、事件绑定（click/change/select）

⚙️

系统层

8 线程池、游戏循环、文件读写、模块系统、通用 callAPI、引用计数内存管理

📝

即写即运行

.w 文件不需要编译，直接运行，修改即生效

🎨

声明式 UI

用声明式语法写窗口和控件，像写 HTML 一样直观

🚀

原生性能

直接调用 Win32 API，无解释器开销，性能接近原生 C 程序

语法示例

声明式写窗口，命令式写逻辑

🪟 最小窗口
window Main { title = "Hello"; width = 400; height = 300; }
🔘 加一个按钮
window Main { title = "Hello"; width = 400; height = 300; button { text = "点我"; x = 100; y = 100; width = 200; height = 50; click = "on_click"; } }
📦 变量
var x = 10; var name = "Alice"; var price = 3.14; var flag = true; x = 20; // 改值 x = x + 5; // x 变成 25
🔧 函数
func add(a, b) { return a + b; } var result = add(10, 20); // 30 // 递归 func fib(n) { if (n < 2) { return n; } return fib(n - 1) + fib(n - 2); } fib(10); // 55
🔄 条件与循环
if (score >= 60) { result = "及格"; } else { result = "不及格"; } for (var i = 0; i < 10; i = i + 1) { print(i); } var n = 10; while (n > 0) { n = n - 1; }
📊 数组
var arr = [10, 20, 30, 40, 50]; var first = arr[0]; // 10 arr[0] = 100; // 修改 // 遍历求和 var sum = 0; for (var i = 0; i < 5; i = i + 1) { sum = sum + arr[i]; }
🧵 线程
func task1() { a = 100; } func task2() { b = 200; } thread_run("task1", ""); thread_run("task2", ""); thread_wait_all();
🎮 游戏循环
var x = 0; var dir = 1; func update() { x = x + dir * 5; if (x > 700) { dir = -1; } if (x < 0) { dir = 1; } } func render() { // 画东西 } window Game { title = "小球"; width = 800; height = 600; fps = 60; on_update = "update"; on_paint = "render"; }

事件绑定

三种事件类型，覆盖常见交互

事件触发时机适用控件
click按钮点击button
change内容改变checkbox, textbox
select选中项改变listbox, combobox
🔗 完整示例：计数器
var count = 0; func on_inc() { count = count + 1; } func on_dec() { count = count - 1; } window Counter { title = "计数器"; width = 400; height = 250; label { text = "计数：0"; x = 100; y = 30; width = 200; height = 40; } button { text = "+1"; x = 80; y = 100; width = 100; height = 50; click = "on_inc"; } button { text = "-1"; x = 220; y = 100; width = 100; height = 50; click = "on_dec"; } }

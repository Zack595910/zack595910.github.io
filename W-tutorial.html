1. W语言是什么

W语言 = 专为Windows界面开发设计的语言，用纯C实现，直接调用系统原生API。

特点：

  • .w 文件即写即运行，不编译
  • 声明式写窗口，命令式写逻辑
  • 直接调Win32/系统DLL
  • 原生性能，无解释器开销

语法长这样：

window Hello {
    title = "Hello W";
    width = 400;
    height = 300;
    button {
        text = "点我";
        x = 20; y = 20;
        click = "on_click";
    }
}

func on_click() {
    var msg = "你好，W!";
}

2. 第一个程序

2.1 最小窗口

新建 hello.w：

window Main {
    title = "Hello";
    width = 400;
    height = 300;
}

运行：

W_Runner.exe

W> cd C:\你的目录
W> hello.w

一个窗口弹出来。就这样。

2.2 加一个按钮

window Main {
    title = "Hello";
    width = 400;
    height = 300;
    
    button {
        text = "点我";
        x = 100; y = 100;
        width = 200; height = 50;
    }
}

2.3 文件结构

一个 .w 文件里，可以按任意顺序写：

  • var 变量声明
  • func 函数定义
  • import 模块导入
  • 顶层语句（赋值、调用等）
  • window 窗口声明
执行顺序：先注册函数 → 加载模块 → 执行顶层语句 → 创建窗口。

3.4 作用域

  • 全局变量：函数外声明
  • 局部变量：函数内声明，函数结束就消失
  • for循环变量：for(var i=...)里的 i 只在循环内有效
var global = 1;

func test() {
    var local = 2;   // 只在这个函数里
    global = 100;    // 改全局变量
}

func test2() {
    var local = 3;   // 另一个局部
    global = 100;    // 也能改全局
}
关键规则：
var x = ... 在当前作用域新建变量
x = ... 沿作用域链找，找到就改；找不到写到全局

7. 循环

7.1 for 循环

for (var i = 0; i < 10; i = i + 1) {
    // i = 0,1,2,...,9
}

结构：

for (初始化；条件；更新) {
    循环体
}

例子：求和

var total = 0;
for (var i = 1; i <= 100; i = i + 1) {
    total = total + i;
}
// total = 5050

7.2 while 循环

var n = 10;
while (n > 0) {
    n = n - 1;
}
// n 最终 = 0
注意：while 不会自动退出，条件一定要能在某处变假，否则死循环。

7.3 循环控制

W 语言目前没有 break / continue。退出循环用条件：

var i = 0;
var running = 1;
while (running) {
    if (i >= 10) {
        running = 0;
    }
    i = i + 1;
}

8. 函数

8.1 定义

func 函数名(参数1, 参数2) {
    // 函数体
    return 返回值;
}

8.2 无参数无返回

func say_hello() {
    var msg = "hello";
}

8.3 有参数

func add(a, b) {
    return a + b;
}

8.4 调用

var result = add(10, 20);  // 30

8.5 递归

func fib(n) {
    if (n < 2) { return n; }
    return fib(n - 1) + fib(n - 2);
}

var x = fib(10);  // 55

W 支持递归，但有深度限制（1000层）。

推荐命名：小写 + 下划线

13. 线程

13.1 启动线程

func worker() {
    // 在线程里跑
    var result = 42;
}

thread_run("worker", "参数");

thread_run(函数名, 参数字符串)。

最多8个线程同时跑。

13.2 等待所有线程

thread_run("task1", "a");
thread_run("task2", "b");
thread_run("task3", "c");
thread_wait_all();

13.3 线程休眠

thread_sleep(1000);  // 睡 1000 毫秒

13.4 完整例子

var a = 0;
var b = 0;

func task1() { a = 100; }
func task2() { b = 200; }

thread_run("task1", "");
thread_run("task2", "");
thread_wait_all();

// 此时 a == 100, b == 200
关键点：线程里写变量，如果变量不存在就写到全局。所以 a = 100 能改到全局的 a。

14. 游戏循环

14.1 概念

游戏循环 = 每帧调用 update 和 render。

  • update() —— 更新状态（位置、逻辑）
  • render() —— 绘制画面

14.2 绑定

window Game {
    title = "游戏";
    width = 800;
    height = 600;
    fps = 60;
    on_update = "update";
    on_paint = "render";
    
    canvas {
        x = 0;
        y = 0;
        width = 800;
        height = 600;
    }
}

on_update / on_paint 既可以写在 window 顶层，也可以写在 canvas 控件里。

14.3 定义回调

func update() {
    // 更新逻辑
}

func render() {
    // 绘制画面
}

14.4 完整例子

var x = 0;
var dir = 1;

func update() {
    x = x + dir * 5;
    if (x > 700) { dir = -1; }
    if (x < 0) { dir = 1; }
}

func render() {
    // 画东西
}

window Game {
    title = "小球";
    width = 800;
    height = 600;
    fps = 60;
    on_update = "update";
    on_paint = "render";
}

15.5 写一个 C 模块（进阶）

#include "w_module_sdk.h"

static int my_add(int a, int b) {
    return a + b;
}

static WMModuleFunc g_functions[] = {
    {"add", (void*)my_add, "int(int,int)"},
};

static WMModule g_module = {
    {"my_module", "1.0.0", "Me", "My module", W_API_VERSION},
    NULL, NULL, 0,
    NULL, NULL, 1, g_functions, 0, NULL, 0, NULL
};

W_MODULE_EXPORT int _stdcall Module_Register(WModule* module) {
    if (!module) return -1;
    *module = g_module;
    return 0;
}

BOOL WINAPI DllMain(HINSTANCE h, DWORD r, LPVOID p) { return TRUE; }

编译成 my_module.dll，就能 import "my_module.dll" 用了。

附录A：常见错误

A.1 "function not found"

原因：调用了不存在的函数。

foo();  // foo 没定义

修：先 func foo(){} 定义。

A.2 事件不触发

原因：回调函数名拼错，或函数没定义。

button {
    click = "on_click";  // 拼错了
}

修：确认 click 的值和函数名完全一致。

A.3 变量改了没用

原因：局部变量覆盖了全局。

var x = 10;

func test() {
    var x = 20;  // 这是新的局部 x，不是全局
}

test();
// 全局 x 还是10

修：函数里用 x = 20;（不加 var）改全局。

A.4 中文乱码

原因：.w 文件编码不是 UTF-8。

修：把 .w 文件存成 UTF-8 编码。
